03 / 08
Architecture — key technical enhancements

Stateful services, stateless code.

One Docker image, four entrypoints. CLIP embeds visual frames keylessly, bge/OpenAI embeds text chunks. Parallel kNN across both Qdrant collections feeds RRF fusion with time-window grouping and cross-modal boost. Storage HEAD-verify and Prefect scheduling run in background threads, keeping accept latency under 250ms. The confidence gate abstains before the LLM when evidence is weak.
